# Rent Monitor

Асинхронный монитор новых объявлений долгосрочной аренды в Москве. Он проверяет публичные страницы поиска, применяет единые фильтры и отправляет подходящие варианты в личный чат Telegram.

Текущий поиск настроен на двухкомнатные квартиры до **70 000 ₽ в месяц** с явно нулевой комиссией. Районы и станции метро не ограничены; коммунальные услуги и депозит в потолок цены не входят.

## Что умеет проект

- приводит результаты площадок к общей модели объявления;
- создаёт начальный снимок найденных ID без первой рассылки;
- повторные объявления отсекает через SQLite, новые складывает в надёжную очередь отправки;
- опрашивает источники по одному, с ограничением размера ответа, таймаутами и паузой при ограничении доступа;
- связывает Telegram-бота с одним личным чатом по одноразовому коду.

Сбор идёт только по страницам, доступным без авторизации. Монитор не использует cookies, аккаунты, прокси, закрытые API и обход CAPTCHA. Публичная разметка сайтов может меняться, поэтому парсеры останавливаются, если страница стала неузнаваемой.

## Состояние источников

| Источник | Текущее поведение |
| --- | --- |
| Яндекс Недвижимость | Использует публичную страницу поиска; принимает только поля, которые удалось явно распознать. При блокировке или изменении разметки приостанавливается. |
| Avito | Сборщик развернут, но VPS получил `access_restricted`; источник автоматически приостановлен и не повторяет запросы. |
| Циан | Приостановлен после отказа публичной страницы поиска. Сетевых запросов не делает. |
| Домклик | Приостановлен: публичный маршрут не подтверждён. Сетевых запросов не делает. |

Служба `rent-monitor` работает на VPS с прежним ботом, привязанным чатом и базой. Сейчас Яндекс Недвижимость активна; Avito остановлен по отказу доступа с VPS, Циан и Домклик также приостановлены. Для Avito уведомления возобновятся, когда публичная страница станет доступна и источник будет вручную запущен после проверки. Если доступ восстановится, опрос будет идти раз в пять минут; к этому добавляется задержка индексации Avito.

## Фильтры

Правила применяются повторно к распознанной карточке. В уведомление попадает только вариант, где известны все обязательные условия:

- Москва;
- ровно две комнаты;
- месячная аренда не выше 70 000 ₽;
- комиссия явно равна нулю.

Неизвестная комиссия не считается нулевой. Если нужного значения нет на странице поиска, Яндекс Недвижимость может проверить одну публичную карточку с отдельным ограничением частоты. Агентства и собственники подходят одинаково, если комиссия нулевая.

Начальная выдача каждого источника становится базой, чтобы при первом запуске не прислать старые варианты. Затем сохраняются нормализованные поля, идентификатор и ссылка объявления, статус источника и очередь уведомлений. Сырые HTML-страницы, телефоны, профили и полные описания не хранятся.

## Локальный запуск и E2E

Нужны Python 3.11 или новее и [uv](https://docs.astral.sh/uv/). Зависимости зафиксированы в `uv.lock`.

```powershell
uv sync --locked
uv run --locked python -m unittest discover -s tests/e2e -v
```

E2E-сценарий использует локальные HTML-фикстуры, SQLite в памяти и поддельный отправитель Telegram. Он не обращается к сайтам объявлений или Telegram и не требует токена.

E2E для Avito подтверждает полный локальный путь от HTML-фикстуры через фильтры и SQLite до поддельного Telegram-отправителя. С рабочего окружения публичный URL ответил HTTP 200, а первый запрос на VPS вернул ограничение доступа. Источник остановился автоматически; реальная доставка объявлений Avito в Telegram пока не подтверждена.

Для новой установки создайте отдельного бота в Telegram и положите его токен в файл `telegram_bot_token` внутри защищённого каталога credentials. Переменная `CREDENTIALS_DIRECTORY` должна указывать на этот каталог. Сам токен не нужно помещать в TOML, Git, аргументы команды или переписку.

```powershell
$env:CREDENTIALS_DIRECTORY = "C:\путь\к\защищённому\каталогу"
uv run --locked rent-monitor serve --config config/search.toml
```

Перед запуском бот нужно привязать к личному чату. Выпустите одноразовый код из того же окружения и отправьте его боту:

```powershell
uv run --locked rent-monitor pair-code --config config/search.toml
```

Владельцу доступны команды `/status`, `/pause` и `/resume`. Команда `/resume` продолжает общий опрос, но не снимает блокировку с площадки, которую остановил сам сборщик.

После ручного обновления и проверки публичного маршрута сохранённую блокировку источника можно снять командой `rent-monitor resume-source <источник>`, затем перезапустить приложение. Эта команда только очищает сохранённый статус: она не меняет сборщик и не обходит ограничение сайта.

## GitHub и изменения

Проект хранится в приватном репозитории. GitHub Actions запускает E2E-сценарий и проверки стиля на Python 3.11–3.14. Для репозитория включены Dependabot alerts и автоматические security updates; Dependabot также обновляет Python-зависимости и GitHub Actions.

Правила для изменений и уязвимостей описаны в [`CONTRIBUTING.md`](CONTRIBUTING.md) и [`SECURITY.md`](SECURITY.md). Конфигурация поиска находится в [`config/search.toml`](config/search.toml), архитектура и принятые ограничения — в [`docs/superpowers/specs/2026-09-25-rent-monitor-design.md`](docs/superpowers/specs/2026-09-25-rent-monitor-design.md).
