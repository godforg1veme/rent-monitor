# Rent Monitor

Асинхронный монитор новых объявлений долгосрочной аренды в Москве. Текущий поиск: двухкомнатные квартиры до **70 000 ₽ в месяц** без комиссии. Новые подходящие объявления отправляются в один привязанный личный чат Telegram.

## Как работает сейчас

| Источник | Состояние |
| --- | --- |
| Avito | Основной источник. Persistent Chromium с обычным профилем проверяет настроенную выдачу примерно раз в минуту. |
| Яндекс Недвижимость | Независимый HTTP-сборщик с более редким интервалом. |
| Циан | Выключен; оставлен для последующей реализации. |
| Домклик | Выключен; оставлен для последующей реализации. |

Каждый источник работает в собственном runner. Ошибка или медленный ответ одного не останавливает остальные и Telegram outbox. При первом распознанном запуске текущие ID становятся baseline и не создают исторический поток уведомлений.

Avito использует один постоянный браузерный профиль: cookies и состояние сессии сохраняются между рестартами. Несколько поисков задаются в `config/search.toml`, выполняются последовательно через тот же браузер и могут иметь разные интервалы. URL, основной контейнер результатов, город и активные фильтры проверяются fail-closed. Карточки рекомендаций вне основной выдачи игнорируются.

Локальная LLM не установлена и для текущих фильтров не нужна. Цена, комнаты, комиссия и время публикации извлекаются детерминированно вместе с признаком происхождения значения. LLM можно добавить позднее только как необязательное обогащение, не в критический путь обнаружения.

## CAPTCHA с телефона

CAPTCHA переводит только Avito в состояние `manual_attention`; автоматические переходы по Avito прекращаются и это состояние сохраняется после рестарта. В личный Telegram приходит owner-only сообщение с кнопками:

1. «Открыть CAPTCHA» создаёт один случайный noVNC-токен на 15 минут и при возможности присылает снимок текущего окна.
2. Ссылка открывает тот же Chromium через Tailscale Serve.
3. После ручной проверки нужно вернуться в Telegram и нажать «Проверить».
4. Опрос возобновится только если текущая страница больше не содержит CAPTCHA и полностью соответствует ожидаемому поиску.

iPhone должен быть подключён к тому же tailnet. VNC `127.0.0.1:5900` и noVNC `127.0.0.1:6080` слушают только loopback; публичного VNC endpoint и Tailscale Funnel нет.

## Фильтры и данные

В уведомление попадает только объявление, где подтверждены обязательные условия:

- Москва;
- ровно две комнаты;
- месячная аренда не выше 70 000 ₽;
- нулевая комиссия явно указана в карточке либо доказана одновременно URL, заголовком и активным фильтром выдачи.

Явная положительная комиссия карточки всегда имеет приоритет. Неизвестное или противоречивое значение не считается нулём. Сырые HTML, cookies, телефоны, профили и полные описания не сохраняются. SQLite хранит нормализованные объявления, baseline, runtime-состояние источников и две долговечные очереди: объявления и системные alerts.

## Состояния `/status`

- `starting` — источник ещё не завершил первую попытку;
- `healthy` — последняя попытка распознана, показаны время успеха и следующая проверка;
- `degraded` — временная ошибка с коротким bounded backoff;
- `cooldown` — сервер ограничил частоту или доступ, следующая попытка отложена;
- `blocked` — повторяющаяся структурная/доступная ошибка с длинной паузой;
- `manual_attention` — автоматические попытки запрещены до ручной проверки, обычно из-за CAPTCHA.

Команда также показывает число последовательных ошибок, последний размер выдачи и newest visible ID. Значимые переходы и восстановление отправляются через отдельный durable outbox без дублирования после рестарта. `/pause` и `/resume` управляют общим опросом; `/resume` не снимает `manual_attention`.

## Локальная проверка

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/):

```powershell
uv sync --locked
uv run --locked playwright install chromium
uv run --locked python -m unittest discover -s tests/unit -v
uv run --locked python -m unittest discover -s tests/integration -v
uv run --locked python -m unittest discover -s tests/e2e -v
uv run --locked ruff check .
uv run --locked ruff format --check .
```

Все тесты используют локальные HTML/HTTP-фикстуры, временную SQLite и поддельный Telegram. Они не обращаются к Avito, другим площадкам или Telegram.

Для локального запуска токен Telegram читается только из `telegram_bot_token` в каталоге `CREDENTIALS_DIRECTORY`:

```powershell
$env:CREDENTIALS_DIRECTORY = "C:\путь\к\защищённому\каталогу"
uv run --locked rent-monitor pair-code --config config/search.toml
uv run --locked rent-monitor serve --config config/search.toml
```

## Развёртывание

Production-схема рассчитана на один VPS и один активный экземпляр long polling. Инструкция установки, Tailscale, smoke checks, backup и rollback находится в [`deploy/README.md`](deploy/README.md). При первом rollout используется немецкий VPS; нидерландский или российский узел не запускаются параллельно с тем же Telegram-токеном и профилем.

Архитектурные решения описаны в [`docs/superpowers/specs/2026-09-26-avito-browser-monitor-design.md`](docs/superpowers/specs/2026-09-26-avito-browser-monitor-design.md), конфигурация — в [`config/search.toml`](config/search.toml).
