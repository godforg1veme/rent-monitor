# Rent Monitor

Rent Monitor ищет новые объявления долгосрочной аренды в Москве и присылает подходящие варианты в личный чат Telegram. Первая конфигурация рассчитана на двухкомнатную квартиру с арендой до 70 000 ₽ в месяц и без комиссии.

Сборщики для Avito, Циан, Домклик и Яндекс Недвижимости работают независимо. Если площадка закрывает публичную страницу или меняет её разметку, монитор отмечает источник как недоступный и продолжает опрос остальных.

## Фильтры

- Город: Москва, без ограничений по районам и станциям метро.
- Комнат: ровно две.
- Аренда: не дороже 70 000 ₽ в месяц. Коммунальные услуги и депозит в лимит не входят.
- Комиссия: только явно нулевая. Если объявление не сообщает размер комиссии, оно не подходит.
- Тип продавца: любой, если комиссия равна нулю.

При первом успешном запросе к каждой площадке найденные ID записываются как начальная база. Уведомления отправляются только о новых объявлениях, которые появились после этого запроса.

## Как устроен сбор

Сервис запрашивает публичные страницы поиска раз в пять минут. В один момент выполняется не больше одного запроса к сайтам объявлений. Для проверки комиссии карточки открываются с отдельным ограничением частоты, когда данных поисковой выдачи недостаточно.

Монитор не входит в аккаунты площадок, не использует cookies, прокси, скрытые API и обход CAPTCHA. При ответе 401 или 403, появлении CAPTCHA либо ограничении частоты источник приостанавливается или замедляет опрос. Доступность публичных страниц зависит от самих площадок; корневая страница с ответом 200 не гарантирует доступ к странице поиска.

В SQLite сохраняются нормализованные поля объявления, его ID и URL, состояния источников и очередь уведомлений. HTML, телефоны, профили продавцов и полные описания не сохраняются.

## Telegram

Нужен отдельный Telegram-бот. Его токен хранится на сервере как systemd credential и не помещается в конфигурацию или переписку. Владелец связывает личный чат одноразовым кодом. Бот показывает новые объявления и поддерживает команды:

- `/status` — состояние четырёх источников и время последней успешной проверки;
- `/pause` — остановить опрос;
- `/resume` — продолжить опрос.

Бот не пишет продавцам и не получает их телефоны или профили.

## Запуск

Требуются Python 3.11 или новее, исходящий HTTPS-доступ к страницам площадок и Telegram. Начальные фильтры находятся в `config/search.toml`.

На VPS проект устанавливается отдельным systemd-сервисом с пользователем и каталогом данных `rent-monitor`. Для процесса заданы пределы 50% одного CPU, 1 GiB памяти, 64 задач и IOWeight 10. Это ограничивает потребление сервиса; ОС, CPU, диск и сеть остаются общими для VPS.

Инструкции по установке и безопасной настройке бота находятся в [`deploy/README.md`](deploy/README.md). До настройки отдельного токена бота сервис не запускается.

## Разработка

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
rent-monitor --help
```

Для запуска на сервере используется тот же пакет, но SQLite размещается в `/var/lib/rent-monitor`, а токен читается из credential directory systemd. Секреты, рабочая база и локальные виртуальные окружения исключены из Git.

## Состояние проекта

Источники и их разметка меняются независимо. Если публичную поисковую страницу нельзя разобрать без авторизации или обхода ограничения, соответствующий сборщик остаётся приостановленным до ручного обновления. На VPS источники проверяются по одному, с интервалами, указанными в конфигурации.

Текущий этап ограничен репозиторием GitHub и E2E-запуском в локальном виртуальном окружении. Развёртывание и проверки на VPS отложены.
