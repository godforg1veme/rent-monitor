# Сообщения об уязвимостях

Не публикуйте токены Telegram, credentials, SSH-ключи, пользовательскую базу, chat ID, cookies и диагностические ответы площадки. Сообщайте владельцу приватно; используйте GitHub Private Vulnerability Reporting, если он включён.

Домашний relay слушает только `127.0.0.1:18781`, VPS forward — `127.0.0.1:18782`. Не открывайте эти порты наружу: relay не предназначен для публичного доступа. Туннель использует существующий SSH-ключ пользователя. Токен Telegram хранится отдельно от Git и передаётся службе через systemd credential.

Worker разрешает только HTTPS-адреса Авито, ограничивает размер ответа и время запроса. Диагностика защиты может содержать активные challenge-токены; каталог должен оставаться доступным только пользователю службы и не попадать в архивы исходников. Сохраняются только последние 12 файлов.

Чувствительные области: credentials, привязка владельца Telegram, SQLite outbox, SSH-туннель, установка внешнего закреплённого кода и systemd-настройки. При обновлении сохраняйте права служебных файлов и резервную копию базы.
