# Сообщения о проблемах безопасности

Если вы обнаружили проблему, затрагивающую секреты, Telegram-привязку, локальную базу или работу сервиса на VPS, сообщите о ней через приватное сообщение или GitHub Private Vulnerability Reporting, если эта функция включена для репозитория.

Не создавайте публичное issue с токенами, содержимым credential-файлов, пользовательскими данными или подробностями, которые помогают использовать уязвимость. Укажите затронутый компонент, условия возникновения и возможное влияние.
