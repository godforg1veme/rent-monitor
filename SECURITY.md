# Сообщения об уязвимостях

Не публикуйте в issues токены Telegram, содержимое credentials, пользовательскую базу или детали, которые позволяют использовать уязвимость.

Для приватного сообщения об уязвимости используйте GitHub Private Vulnerability Reporting, если он доступен в настройках репозитория. Если функции нет, свяжитесь с владельцем репозитория приватным способом и укажите затронутый компонент, условия возникновения и возможное влияние. Не прикладывайте токены и реальные данные объявлений.

К чувствительным областям относятся хранение credentials, привязка Telegram-чата, SQLite outbox, HTTP-ограничения и подготовленные systemd-файлы.
